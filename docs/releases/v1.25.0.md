# v1.25.0 · 无限画布换用 react-flow 引擎；LibTV 式缩放菜单与视图开关

> 各版本改动见 [CHANGELOG.md](../../CHANGELOG.md)。

## 画布引擎：@xyflow/react

无限画布的渲染与视口交给 react-flow v12（受控视图），对齐 LibTV 一类产品的底层
引擎；**现有功能全部保留**，用户磁盘上的画布数据零破坏。

- **唯一真源不变**：`CanvasDocument` v2 仍是文档层真源，宿主校验、revision 乐观锁、
  自动保存、撤销重做（60 步、视口不入历史）全部留在文档层，react-flow 只做受控视图。
- **混合架构**：react-flow 负责节点渲染、视口 transform、拖拽平移与滚轮缩放；
  节点拖动（边缘对齐吸附、标注卡随行、重叠提示）、四角 resize、选择、连线、
  捏合缩放、框选保留自定义引擎——既有手势与快捷键一个不丢。
- **无损适配层**：新增 `canvas-flow-adapter`（节点/连线/视口双向 round-trip，
  metadata 全字段保留，「无 metadata」与「空 metadata」的区别保住）与
  `canvas-flow-context`（模块级稳定节点外壳，探针与事件路由照旧）。连线持久化
  仍存 `{fromNodeId,toNodeId}`，workflow/compose/storyboard 的纯函数契约不动。
- **构建**：react-flow 及其依赖内联进 bundle，样式构建时经 lightningcss 内联注入；
  跨目录可复现构建字节一致。

## LibTV 式 chrome

- **缩放预设菜单**：点缩放百分比打开——放大/缩小/适应全部内容、50%/100%/200%/
  400%/800% 预设、自定义百分比输入；缩放上限 500% → 800%。
- **视图开关**：对齐吸附（默认开，关掉后拖动不再吸附节点边缘）、显示连线
  （隐藏持久边，进行中的连线预览与技能运行边不受影响）。
- 菜单文案补齐 zh/en/ru 三套。
