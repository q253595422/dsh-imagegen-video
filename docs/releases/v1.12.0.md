# 1.12.0 — 一条片子该有的三件事：剪、接、认人

这一版补的是「已经能逐镜生成之后」还缺的三层：把成片排成时间线、让同一个人
在每一镜里都还是他、以及一套可改的转场。三件事共用同一个原则——**成品仍然是
普通视频节点**，没有第二套工程文件，也没有第二种节点类型。

## 时间线：先排、再剪、然后才拼

- **时间线面板。** 画布底部新增「时间线编辑」入口：选中的成片按画布阅读顺序
  排成一条，可以直接上下移动、移出、调整顺序。没有选区时自动取画布上全部
  成片，少于两段时说明原因而不是打开一个空面板。
- **每段可以裁。** 每段给出入点与出点，按素材的真实时长夹住——出点填成 99
  秒不会让 ffmpeg 去读不存在的帧，只会切到结尾。时长未知的素材照常显示，
  只是不参与总时长的计算。
- **接缝上有转场。** 硬切 / 叠化 / 淡入淡出三选一，可调时长。转场时长在
  **计算期**就被夹到两侧素材的一半以内（并留 0.05 秒余量），所以不会出现
  ffmpeg 报一个看不懂的偏移错误。面板上的总时长和文件里的长度是同一套算法。
- **音频轨可选。** 关掉「保留声音」后成片不带音轨，省掉一次重编码后的静音轨。

底层是真正重写过的：全硬切走一次 `concat`，任一转场走链式 `xfade` /
`acrossfade`，接缝两侧统一时间基（`settb=AVTB`）。`-c copy` 在这里不可用——
输入尺寸或帧率不一致时它会静默产出一个坏文件，所以显式 filtergraph 重编码。
`pnpm test:timeline-compose` 会用本机 ffmpeg 真跑四种形态并校验成片时长；
机器上没有 ffmpeg 时明确跳过，不伪装成通过。

时间线的规则是纯函数（`src/client/timeline.ts`），`pnpm test:timeline` 离线
验证裁剪、总时长、转场上限与归一化。

## 身份锚定：定义一次，后面每一镜都带着

- **钉住一张脸。** 任意有图的图片节点右键即可「钉为身份参考」，选角色
  （角色 / 物品 / 风格）并起个名字。节点上会出现一枚角标，提示词里也会补
  一句「参考图 1 是角色「阿禾」，保持同一个人」。
- **后续生成自动带上。** 图像生成与视频生成都会把被钉住的节点并进参考图，
  不需要每镜重新连线。连线仍然优先——它表示「这一张的输入」，身份是「这部
  片子的设定」，两者合并去重：同一张图不会送两次，同名只送第一个。
- **视频模式会因此升级。** 什么都没连、但有钉住的角色时，自动从文生视频切到
  参考图模式，而不是悄悄退化成一次没有参考的生成。
- **改脸只改一处。** 定义就在那个节点上，重拍它，后面所有生成自动跟着变。
  这是把 `metadata.cast` 放在节点上、而不是新建一个角色库的原因。

规则同样是纯函数（`src/client/cast.ts`），`pnpm test:cast` 离线验证收集、
去重与提示词生成。

## 契约与边界

- **没有新增节点类型。** 时间线的成品、被钉住的身份，都是普通节点上的属性，
  所以预览、下载、收藏、重试、再拼接全部照旧。
- **旧画布原样打开。** 没有 `metadata.cast` 的文档行为与 1.11 完全一致；
  没有 `timeline` 参数的拼接请求走原来的整段硬切路径。
- **格式错误的 `timeline` 参数会被拒绝**，而不是静默退回普通拼接——静默退回
  意味着用户以为设了转场，文件里却没有。
- z-index 没有新增档位：时间线面板与身份面板复用 `--z-notice`。
