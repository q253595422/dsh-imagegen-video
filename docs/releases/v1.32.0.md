# v1.32.0 — 姿势人偶升级成导演台：一个场景、多个角色、多台机位

> **版本说明**：本版把 `v1.31.0` 里的「原生姿势节点」升成「导演台」。节点类型没变（仍是 `type: 'image'` + metadata 活数据 + 导出 PNG），老画布零迁移。

## 之前是什么样

一个姿势节点就是**一个人**：17 个关节、11 个预设、一张 1024 PNG。想画两个人对话，只能放两个独立节点——它们各自有自己的相机、自己的地面、自己的光照，拼在一起像是两张贴图并排，而不是一个场面。

## 现在

一块卡片瘦成「预览 + 机位名 + 打开导演台 + 预设条 + 生成参考图」，摆位与摆姿搬进全屏面板：

- **左栏**：场景列表（机位与角色一起列，可搜索、可增删）。
- **中央视口**：导演视角 / 机位视角切换，拖动环绕，滚轮缩放，X/Y/Z 罗盘，机位视锥线框。
- **右栏**：场景缩放/平移/旋转、天空色、全景背景、角色标签、当前角色或机位的参数。
- **底部**：机位截图、一句话场景描述。

### 三个角色、三种姿势，一张画面

多角色不是把所有人的球体并进同一个距离场——距离场是**屏幕空间**的，合并之后两个人接壤处的轮廓会被 smooth-min 融成一块，后排的人像贴在前面那人身上的一个鼓包，前后关系彻底丢失。每个角色各自成一张遮罩、按中心深度排序、依次贴上去，遮挡才成立。

### 加了人就立刻重新取景

新角色排在已有角色右边 1.2 m。不重新取景的话它会站到画面外，用户看到的是一张没变化的图，只会以为按钮没生效，然后一直点，最后堆出五个看不见的人。

这条也牵出一个更深的问题：环绕相机原先只有 `targetY`，**水平注视点被硬编码在原点**。三个人并排时只把相机拉远是不够的——画面中心仍然盯着原点，第三人被裁在画外。现在 `PoseCamera` 带可选的 `targetX` / `targetZ`（缺省即 0，姿势面板的行为不变），取景会真的把画面中心挪到人群中间。

### 老文档零迁移

- 只有 `metadata.pose` 的老节点：按单角色舞台读出来，不写盘、不改字节。
- 写盘时 `stage` 与 `pose` 一起写，`pose` 镜像 `actors[0].rig`——一份带三个角色的文档在旧版插件里仍是一张能用的姿势人偶，而不是一张读不懂的图片。
- 读盘以 `stage` 为准：`pose` 没有能力表达其余两个角色。

### 成品仍是普通图片

机位截图导出一张 1280×1280 PNG，落成节点的 `asset`。下游的生成、标注、图库、导出都不必知道「导演台」存在。

## 底栏：从 18 个图标到三档层级

原来的底栏是一排 17 个 40px 方块，外加 5 条 1px 竖线。每个都是一个同权重的图标，只有悬停才显示名字——用户要找「新建」，得把整排读完。竖线还让每一格看起来像表格里的一个单元格。

现在只有三档：

1. **一个实底 `+`**（左）。文本、画板、姿势、分镜、文件、配置六种节点收进它的菜单。`+` 是「新建」的通用形状，不必再解释。
2. **一排低调的图标**（中）。工具、图片、模板库、技能库、时间线、背景、快捷键、撤销重做、删除。分组靠留白——1px 线画出来的是表格，不是分组。
3. **一个带文字的主动作**（右）。「运行工作流」说自己的名字，右侧箭头并进同一块药丸、只开选项菜单。在画布上它是最常用的一步，一排纯图标只能靠逐个悬停学会。

两处与弹簧引擎的边界是显式的：实底 `+` 仍是 40px 方块（照常被放大），带文字的主动作用 `data-dock-static` 退出引擎——引擎写的是内联 `width`，那会把文字药丸压回 40px 并裁掉标签。

## 这一版没做

- **多机位切换成片**：机位能加、能切、能各自取景，但还不能一次导出「每个机位一张」。
- **AI 搭场景**：底部那行场景描述存在节点上，还没有接到生成链——静默丢掉用户敲的字比留一个不触发的字段更糟，所以它先被完整保存。
- **全景球是真球面**：现在按水平旋转贴一条环绕带。完整球面反投影要逐像素求逆矩阵，代价远高于它带来的收益。
- **视口内直接拖角色站位**：站位在右栏用 X/Z 数字框改。

## 验证

- `scripts/smoke-pose-stage.mjs`（20 条）：老文档兼容、双写镜像、加角色/机位不重叠、畸形缩放不塌成一点、取景跟人群中心、**每个角色的每个关节都投影在画面内**、提示词往返、站位参与变换。
- `scripts/verify-pose-panel.mjs`：真浏览器量 320×360 / 240×360 / 220×300 三档，钉住「打开导演台」按钮不被挤掉、机位名不与按钮重叠、矮卡片里预览收缩而不是把导出按钮顶出去、最后一枚预设可滚达。
- `pnpm test` 全绿（含 native-UI 契约与 z-index 契约）。
- `scripts/verify-canvas-layout.mjs`：五档面板宽度量底栏与缩放条/小地图的重叠与越界，并**数行数**——720px 及以上必须单行。这条是拿真机发现的：分组间隔取 10px 时，900px 面板下「删除」单独掉到第二行，看着像少了一个按钮，而重叠与越界两条都看不见它（那枚磁贴仍在画布内、不碰任何东西）。

其中两条检查是从真机走查里回来的：遮罩贴回时漏了 `fieldCell` 倍放大（人偶体块只有骨架的 1/2.4），以及上面那条水平注视点。
