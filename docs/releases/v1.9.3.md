# v1.9.3 · 会话图片、PPT 交付与 xAI Grok 视频

> 各版本改动见 [CHANGELOG.md](../../CHANGELOG.md)。

本版把上游 1.9.1 与 1.9.2 的 PPT 交付改动合进来，并修掉本仓库自己的两处问题：
会话里的生图结果能显示图片了，「图片转 PPT」在窄栏下不再被挤出屏幕，Grok 视频接上了官方接口。

## PPT 转换

- **宿主错误不再被「未输出最终 PPTX」掩盖。** 模型或执行失败时保留具体错误并脱敏，
  没有回复时提示检查默认模型连接与工具配置。
- **接收上游 skill 自己 final 目录里的最终 PPTX。** 只接受完成记录加通过的校验报告，
  继续检查 PPTX 结构与页数；中间页文件不会被当成成功结果。
- **配置改为页内弹窗**，复用生图配置里的同一组字段，不再依赖宿主设置按钮的 DOM 查找；
  支持 Escape、焦点约束与返回原按钮。
- **上传后是缩略图网格加「＋」卡片**，可点击预览、移动顺序、删除；顺序即幻灯片顺序。
- **结果区只展示最终 PPTX。** 左右两栏：左边图片与参数，右边自动打开内容预览，
  支持缩略图翻页、上一页/下一页、放大与下载；窄屏改单列，图片列表独立滚动。
  新增任务诊断入口，预览失败可重试且仍可下载文件。复杂版式以 PowerPoint 为准。

## 会话与画布

- **会话中的生图工具读取 DSH 持久化的结果 metadata**，文生图、图生图与任务查询返回的
  图片都能显示缩略图并打开原图；旧会话里的图片内容块与 JSON 引用仍然兼容，重复附件只显示一次。
  图片只作界面展示，发给模型的内容仍是文本。
- **修复 PPT 首条消息的 `format v4 message requires a producer-owned source kind`**：
  改用 `plugin:dsh-imagegen`，不再用被 DSH v4 拒绝的旧 plugin 包装；无限画布里的重型 skill 同样生效。

## 视频

- **Grok 视频接入官方协议。** 新增 `xai` 家族：提交到 `/v1/videos/generations` 读 `request_id`，
  轮询 `/v1/videos/{request_id}` 读 `video.url` 与 `video.duration`，`failed` 与 `expired` 都按失败报告。
  请求体按官方约定发送数字 `duration`、小写 `resolution` 与 `image: { url }`。
  `xai-grok` 预设自带 `grok-imagine-video-1.5` 与 `-lite` 两个视频模型。

## 其它

- **窄栏布局不再被挤出屏幕。** 中间列很窄时对话区按内容收缩，工作室整体滚动，
  配置栏不再撑破布局；生成按钮与画布都可达。
- Windows 桌面宿主的在线更新改走宿主安装接口，安装结果逐项核对，不接受「看起来成功」。

## 验证

类型检查、构建与 93 项离线检查通过，另有反向验证确认每处守卫被改回时对应检查会变红。
PPT 工作区的真实浏览器检查（`pnpm run ppt:preview && pnpm run test:ppt-browser`）需要 Playwright
与 Chromium，本机未安装时明确跳过并返回成功；等价的 jsdom 覆盖在 `pnpm test` 的 E1 里。

本环境没有用真实付费模型跑通整份多页转换，转换质量仍取决于输入图片、OCR 与模型能力。
