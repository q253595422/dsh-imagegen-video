# v1.22.0 · 预览关得掉、深色画布看得清，外加 Agnes 图像/视频

> 各版本改动见 [CHANGELOG.md](../../CHANGELOG.md)。

本版修掉两个「功能其实在，但用不了」的问题，并接入 Agnes 的图片与视频协议族。
两个 bug 都有个共同点：**原来的测试是绿的**，因为它们量错了对象。

## 大图预览

- **关闭按钮一直在，只是看不见。** 白色图标画在 16% 白的圆盘上，下面再叠 82% 黑遮罩：
  图标与圆盘之间 8.15:1，圆盘与遮罩之间只有 1.67:1，描边 2.03:1。原来的检查量的是
  「图标 vs 自身表面」，所以连圆盘彻底消失都照样满分——它验的是字看得清，不是按钮找得到。
  现在把边界放在描边上：填充要抬到 40% 才够 3:1，而白字放在 40% 填充上会掉到 3.9:1，
  等于用丢掉文字换来边界。浮在照片上、不承载文字的圆形按钮（关闭、左右翻页）同时给
  40% 填充与 55% 描边；带文字的药丸保持原样。实测填充 3.52:1、描边 5.26:1。
- **一次滚轮只做一件事。** 原来的处理器写了 `preventDefault()`，但 React 18 把 `wheel`
  注册成 passive，那句是死代码——浏览器照常滚动，同时处理器又改了缩放，所以一次滚轮既
  滚动又缩放。现在改用原生非被动监听，**普通滚轮滚动、Ctrl/⌘ + 滚轮缩放**，界面上写明
  了这条规则。两个修饰键都认：报障用户在 Windows，插件也发行到 macOS。
- **预览里的滚轮不会再滚到后面的工作台。** 遮罩是 `position: fixed`，鼠标停在工具条或
  说明文字上时，滚轮原本会滚到底下的工作台（实测 300px）。现在遮罩自己吸收滚轮，
  停在预览内的任何位置都不会带动背后。

## 无限画布

- **节点与背景原来是完全同色，不是「接近」。** 两者画的是同一个主题 token，对比度实测
  1.00:1。换一层也不行：深色下相邻层只差 1.298:1，浅色下三层全解析成 `#ffffff`。
  现在用「背景反色」混出节点表面，同一句声明在两套主题下方向自动正确——深色时节点更亮
  （1.87:1），浅色时节点更暗（1.29:1）。
- **边框达到 3.07:1**（原来 1.16:1），越过 WCAG 1.4.11 对非文本边界的 3:1。
- **悬停只加强静止态。** 悬停一个已选中的节点不会再把它降回悬停强度。

## Agnes 图像 / 视频

- **图生图不再必然 503。** 此前这类模型按 OpenAI 编辑协议发 `POST /images/edits`，
  而 Agnes 没有这个端点，网关回 `503 no available server`。现在编辑走
  `POST /images/generations`，参考图放进 `extra_body.image`，输出格式也写在 `extra_body` 里。
- **文生图不再必然 400。** 只要用户选了清晰度档，原来的请求就带 `quality`，而 Agnes 对它
  直接返回 400。这两类 OpenAI 专有字段现在只按协议族发送。
- **视频档位与文档对齐。** Flash 只接受 `720P`，其他值在创建任务前就 400；参考图上限 5 张；
  画幅补上实测可用的 `21:9`；轮询放宽到 2s / 40 分钟——实测一个 4 秒片子建完后 35 分钟
  仍在排队，原来的 20 分钟上限会把还在排队的任务误报成超时。

## 关于验证

两个 bug 的修复都补了真浏览器契约检查，并且每条都配了**反向用例**：把缺陷注回仓库副本，
对应检查必须变红。反向用例这次还抓出过一次自己写的假绿——遮罩穿透的检查最初把监听写死在
测试页面里，等于自证，改正为由源码驱动后才真正会在缺陷下变红。
