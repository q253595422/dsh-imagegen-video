# v1.20.0 · 接入 snapgen.ai 视频模型

本版新增 snapgen.ai 视频协议族，把 Grok / Muse / Vela 系列视频模型接进插件；同时把视频时长与画面比例的选项改成由模型目录驱动，并解除“渠道必须至少有一个图片模型”的限制。

## 主要更新

- **新增 `snapgen.ai` 渠道预设**，支持 `grok-1.5-lite`、`grok-video`、`grok-lower`、`muse-ai-video`、`vela-ai-video`：
  - 该服务不是 OpenAI 兼容接口，`src/snapgen-engine.ts` 单独实现四条差异：multipart 提交 + 自研反爬守卫头
    `x-guard-id`；返回历史 uuid 而不是任务 id；`GET /history/{uuid}` 用数字状态（1 生成中 / 2 完成 / 3 失败）；
    成片地址在 `generated_video[0].video_url`（预签名，未鉴权即可下载）。`video-engine.ts` 只做编排。
  - 密钥栏填 **refresh_token**：Access Token 只有约 10 分钟有效期，且过期返回的是 HTTP 403 `TOKEN_EXPIRED`
    而不是 401，所以引擎按 JWT `exp` 提前续期，并在收到带 TOKEN 字样的 403 时强制刷新后重试一次。
    接受原始 refresh_token、`{"refresh_token":"…","cdp_port":9333}` 形式的 JSON，或仍在有效期内的 access_token。
  - 每次提交都需要一枚一次性 Cloudflare Turnstile token（绑定 site key，无法缓存或本地计算），
    由本机 CDP Chrome 在真实 snapgen.ai 页面上现场换取：默认端口 9333，无头 Chrome 亦可。
    换不到时错误码为 `snapgen-turnstile`。
- **按模型收窄时长与比例词表**：`grok-*` 为 6/10/15 秒，`muse-ai-video` 固定 10 秒，`vela-ai-video` 固定 5 秒；
  比例在 `grok-*` 上映射为 landscape / portrait / square / 3:2 / 2:3，在 `muse`/`vela` 上只有前三种。
  视频面板与画布作曲家的时长、比例、分辨率下拉都改为读 `describeVideoModel()` 的目录数据，
  不再写死 `[5, 10]` 与 `['16:9','9:16','1:1']`。
- **只有视频模型的渠道可以保存**：以前 `validateChannelDraft` 要求至少一个图片模型标识，只接视频的渠道存不下来；
  现在图片或视频模型任一非空即可，侧栏的就绪状态与模型计数也一并按两者合计。
- **预设列表显示并可搜索视频模型**：预设行原来只展示图片模型别名，snapgen 这类纯视频预设会显示为空白；
  现在搜索与行内说明都包含视频模型别名。
- **修复浏览器布局守卫的假失败**：`verify-video-layout.mjs` 用 1520px 宽的窗口描述问题，却从未设置视口，
  无头 Chrome 默认 756×469 会命中样式表自己的 `@media (max-width: 760px)` 断点，把生成行折成一列后
  报出并不存在的“37% 太窄”。现在用 `Emulation.setDeviceMetricsOverride` 固定视口，守卫测得 97% 通过。
- **修复对比任务并发断言在负载下抖动**：模拟上游的重叠窗口只有 50ms，整套测试并行跑时会退化成串行，
  报 `maxGenerationRequests===1`。窗口放宽到 300ms，断言仍是“两条请求在上游重叠”。

## 验证

- `tsc --noEmit` 0 错，`pnpm build` 通过。
- 离线冒烟新增两组断言：守卫字节与线上实测值逐字节对齐（含 `/api` 前缀参与签名的证明），
  以及空密钥 / 不支持的生成模式在触网前就失败并留下诊断记录。`smoke-video.mjs` 33 项全过。
- 通过插件本体的 `generateVideo()` 对 api.snapgen.ai 实跑出片：
  文生视频 `muse-ai-video` 10 秒 4.3 MB、图生视频 10 秒 7.7 MB，`ffprobe` 均为 h264 + aac 的有效 MP4。

## 已知限制

- `vela-ai-video` 提交会被接受，但服务端当前稳定返回 `HIGH_TRAFFIC_ERROR`（页面也标为维护中），插件如实透传该错误。
- `grok-video` 与 `grok-lower` 需要付费套餐，免费账号上游返回 `DAILY_LIMIT_EXCEEDED`（错误码 `snapgen-quota`）。
- grok 系列是否接受参考图（`files` 字段）尚未实测：免费额度只有每天 5 条，当日额度已用尽。
