# v1.6.8 · 侧栏切换与圆角菜单优化

> **上游的历史发布说明，按原样保留。** 本仓库的 fork 基线就是这个版本（tag `v1.6.8`），
> 所以文中的安装命令写的是上游包名 `@dickpy/dsh-imagegen`。安装**本仓库**请用
> `dsh plugin --profile web add @q253595422/dsh-imagegen-video`，本仓库相对上游的
> 改动见 [CHANGELOG.md](../../CHANGELOG.md)。

本版改善会话与生图面板之间的切换，并统一插件内的下拉菜单样式。

## 主要更新

- **直接返回当前会话**：侧栏切换器改为“会话 / 生图”。点击“会话”会返回原来的聊天，不再新建会话；独立的原生“新会话”按钮继续保留。感谢 @WesleyLiuCaiyin 的交互改进（[#37](https://github.com/dickpy/dsh-imagegen/pull/37)）。
- **生图模式下也能新建会话**：修复原生按钮被侧栏样式隐藏的问题。按钮被容器包裹或重新渲染后仍能正确显示，点击时保留原生创建行为并关闭生图面板。
- **统一圆角下拉菜单**：历史模型与比例筛选、素材库排序、电商表单、设置页和画布项目切换等 17 处原生下拉框采用统一菜单；画布比例与质量菜单也复用相同样式。圆角、选中底色与悬停态保持一致，颜色跟随当前主题。
- **完善菜单操作**：支持方向键、Home / End、Enter、Esc、Tab 和键入查找；保留分组选项，菜单会避开侧栏裁切，并根据窗口空间调整展开方向。

## 兼容性

- 不新增运行时依赖，现有渠道、历史记录、素材库、模板和画布数据无需迁移。
- 更新后重新加载页面或重启 DSH，即可使用新的界面。

## 安装

```bash
dsh plugin --profile web add @dickpy/dsh-imagegen@1.6.8
```

从本页的 tgz 附件安装：

```bash
dsh plugin --profile web add <下载路径>/dickpy-dsh-imagegen-1.6.8.tgz
```
