# v1.18.0 · PPT 转换进度、会话归属与侧栏稳定性

> 各版本改动见 [CHANGELOG.md](../../CHANGELOG.md)。

本版三件事：PPT 转换能看见真实执行进度、历史记录不再因保存失败而丢，
生图结果加入对话时不再猜错会话，侧栏重复加载后不再出现两个历史面板。

## PPT 转换

- **任务记录改为不可变快照，不再重命名覆盖同一个 JSON。** 旧写法在 Windows 上会撞上
  目标文件被占用（EPERM / 共享冲突），导致整个转换失败；现在每次写入落一个新文件，
  读取时取版本号最大的完整快照，残缺文件自动跳过。旧格式的 `skillrun-<id>.json`
  仍然能读出来，只是不再被覆盖。
- **保存历史出错不再中断已经开始的转换。** 真正的转换错误和「历史没存上」分开表达：
  前者让任务失败，后者只在结果区挂一条提示，成功的 PPT 不会因为写盘失败被改判成失败。
  历史目录读不出来时，当前进程里还在跑或已完成的转换仍然可见、可预览、可下载。
- **右侧新增真实执行进度。** 显示当前操作、最近活动时间、页级校验状态和执行记录；
  页数只来自上游 `page_jobs.json` 的实际校验记录，**没有按时间估算的百分比**。
  长时间没有新事件时如实说明「可能仍在运行」，不宣称卡死也不宣称完成。
  诊断里同步给出 `progress`、`persistenceError`、`stage`、`phase`。

## 生图结果加入对话

- **加入前先确认真实当前会话。** 优先用宿主会话列表里的当前选择；取不到时弹出会话选择器，
  由用户明确指定目标，**不会按列表顺序自动挑一个历史会话**——那正是把图片塞进错对话的原因。
- **选择器不预选任何一项。** 用户没选过之前确认按钮保持不可用；打开期间会话若被删除，
  提交时会重新核对，不会写进一个已不存在的会话。
- **附件路径完整保留**：创建草稿附件、注册到会话输入、写入服务端附件；失败时回滚临时草稿。

## 侧栏与界面

- **一个文档只保留一棵生图 UI 树。** 宿主重复应用客户端时，旧树的 portal 和设置订阅会被释放，
  侧栏不再收到多个历史面板。
- **侧栏历史宿主与生图面板补上不透明底色。** 宿主或壁纸主题把 `--dsw-alias-bg-base`
  设成透明时，不再透出底层内容。

## 验证

`pnpm run typecheck` 0 错、`pnpm run build` 通过、`pnpm test` 全绿（`EXIT=0`，0 FAIL，
0 skipped，`UI CONTRACTS VERIFIED`）。新增三项检查：`C11ppt-progress`（进度只来自真实事件与
页面记录，不含模型思考、工具输出和编造的百分比）、`C11ppt-store`（模拟 Windows 替换锁、
并发写入与残缺快照）、`conversation-sync` 四个单元用例。反向验证：把快照写入的串行化去掉后
`C11ppt-store` 立刻报 FAIL，确认断言有判别力。

**已知未验证**：`page_jobs.json` / `run_state.json` 在真实运行目录里的落盘位置没有实跑确认过
（进度卡按 `runDir` 向下 6 层查找），页级进度首次真机转换前可能显示为等待；
未在 DSH Web / Windows Desktop / macOS Desktop 宿主中实机验证。
