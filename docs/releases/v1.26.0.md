# v1.26.0 — 画布布局对齐 LibTV

真机对比 LibTV 画布后，把画布内部 chrome 的布局骨架对齐过去；配色仍跟随宿主主题，插件外框（顶部功能 tab、宿主侧栏历史）按拍板保留不动。

## 改动

- **悬浮顶栏**：顶栏不再占布局高度，画布铺满整个区域；玻璃细栏浮在画布上方，项目下拉、双击重命名、收藏、删除、全屏、保存状态原样保留。新节点落点语义不变（中心点只扣底部 dock）。
- **左下工具排**：网格吸附、显示连线两个开关从缩放菜单铺平为独立按钮，`aria-pressed` 暴露状态、高亮可见；与小地图、适应屏幕、缩放百分比并排成 LibTV 式左下一排。缩放菜单保留 50–800% 预设与自定义输入。
- **分组 dock**：17 个动作按「工具｜建节点｜库｜运行｜编辑｜删除」六组重排，组间发丝分隔；tile 命中区 40px，hover 出标签。动作一个不删。
- **空态快捷卡**：画布无节点时居中提示 + 一排五张快捷卡（图片生成/视频生成/文本/分镜/文件），点一下即用现有创建动作在画布中心建节点；视频卡走现有视频选择器。一旦有节点，卡片退场。zh/en/ru 三语。
- 窄屏（≤760px）顶栏换行、选择器与标题收窄，不横向溢出。
- **真机走查修掉两个手势缺陷**：① 框选分支把空态快捷卡当空白，pointerdown 的 preventDefault+指针捕获抢走卡片 click——框选现在排除 `data-canvas-no-zoom` 面；② react-flow 在三开关全 false 时给节点 wrapper 设 pointer-events:none 且可继承，卡片本体收不到真指针、拖拽死掉——`.node` 外壳恢复 auto（交互子元素各自阻断冒泡，编辑/按钮不受影响）。两条都配了契约不变式与反向用例。
