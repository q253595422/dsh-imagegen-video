# v1.7.3 · 数据根支持 `~`，拖拽柄跟随界面语言

> 各版本改动见 [CHANGELOG.md](../../CHANGELOG.md)。

两个都不大、但都属于「用户照直写就会踩」的问题。

## 主要更新

- **数据目录设置里的 `~` 现在表示用户主目录。**
  这个值是手打进设置表单的，在那里 `~/my-images` 是最自然的写法，
  而 `path.resolve` 不会展开它——于是宿主会在自己的工作目录下建一个**字面叫 `~` 的目录**，
  把东西全存进去，用户去主目录找却什么也没有。`~user` 形式刻意不动。
- **聊天区拖拽柄的 `aria-label` 跟随界面语言。**
  它在 React 树之外创建一次，DSH 切换语言时没有任何东西会重新渲染它，
  于是它一直停留在创建时的那门语言。现在它会订阅语言变化，
  并在元素被替换或面板卸载时释放订阅。

## 兼容性

- 不新增运行时依赖，无需迁移。
- 如果你此前把数据目录写成了 `~/...`，升级后数据根会**变到主目录**下真正的位置；
  旧的字面 `~` 目录里的数据不会自动搬过去，需要手工移动。

## 安装

```bash
dsh plugin --profile web add https://github.com/q253595422/dsh-imagegen-video/releases/download/v1.7.3/q253595422-dsh-imagegen-video-1.7.3.tgz
```

从本页的 tgz 附件安装：

```bash
dsh plugin --profile web add <下载路径>/q253595422-dsh-imagegen-video-1.7.3.tgz
```

- `pnpm exec tsc --noEmit` 通过；`pnpm test` 全链通过（七个套件）。
