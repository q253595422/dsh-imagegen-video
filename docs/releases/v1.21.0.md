# v1.21.0 · 画布底部工具条自适应，Agent 生成结果可直接内嵌

本版修掉无限画布底部三件浮层（任务工具条、缩放条、缩略图）互相压盖的问题，让窄面板下换行避让而不是叠在一起；
同时给 Agent 的图片工具补上落盘路径输出，模型可以在回复正文里直接内嵌生成结果。

## 主要更新

- **画布底部浮层不再互相压盖，窄了就换行。** 任务工具条、缩放条、缩略图原来是三个各自绝对定位的图层
  （`left: 50%` / `left: 14px` / `left: 14px; bottom: 62px`），彼此不知道对方尺寸。在三栏布局下画布实际只拿到约 1000px，
  711px 的任务工具条与 236px 的缩放条横向重叠约 107px，压住缩放条最左侧的「选择 / 平移 / 添加图片 / 添加文本」四个按钮；
  面板窄到 560px 时工具条还会溢出左边被裁掉。这类重叠取决于**面板**宽度而不是窗口宽度，所以 `@media` 断点测不到，
  jsdom 也没有排版引擎，整套测试一直是绿的。
  现在三者合并成一个 `.canvasChrome` 换行 flex 行：宽度够时同排，不够时任务工具条换到第二行而不是盖上去；
  任务工具条自身也会在面板比它窄时把 17 个按钮折行。侧列固定靠左，任务工具条用 `margin-inline: auto` 居中，
  换行后它独占的一行同样居中。
- **画布给底部浮层留出真实高度，「适应全部内容」不再把节点放到工具条后面。** 底部浮层浮在画布之上、不占布局空间，
  所以 `fitView` / 新建节点 / 新画布种子节点算的都是被遮挡的几何中心。现在用 `ResizeObserver` 实测
  `视口底 − 任务工具条顶` 的差值（不是浮层总高：缩略图在左侧、不挡中间，按总高留会白扔 150px），
  三处都减掉它。之所以实测而不是写常量，是因为折行、以及 Hover 时弹簧动画都会改变这个高度。
- **Agent 生成结果输出落盘绝对路径，支持在回复正文内嵌图片。** `generate_image` / `edit_image` 的工具结果新增
  `files`（当前生成图的绝对路径）与 `embed_id`；`generate_image` 与 `edit_image` 提交时带 `agentTool` 标记，
  用来把 Agent 生成与面板手动生成区分开。最终回复在最前面用 Markdown 图片语法内嵌、说明文字在后。
  不新增任何 UI 注入，官方工具卡与工作步骤展示保持原样。
- **修复 `files[]` 永远是空数组。** 上一条最初只读取 `task.result.embedId`，但没有任何地方给它赋值：
  生成路径在 `history.append()` 里内联构造历史 id，结果回来时没有这个字段，`taskResult()` 直接短路成 `files: []`。
  现在两条路径（模型生成与代码渲染）都先建好 id、再交给 append，并且只在 store 确实列出了该条目时才回显 `embedId`
  ——写盘被静默丢弃时不会给出磁盘上并不存在的路径。
- **白给一个画布全屏控件。** 顶栏新增全屏按钮，走真实 Fullscreen API；从任何途径退出全屏（Esc、浏览器自身控件）
  都会回写到按钮状态。模板库抽屉改为挂载到画布根节点——挂到 `<body>` 的 portal 在全屏元素之下会被盖住。

## 验证

- `tsc --noEmit` 0 错，`pnpm build` 通过，`pnpm test` 全套通过。
- 新增真浏览器布局守卫 `scripts/verify-canvas-layout.mjs`：在 997 / 860 / 720 / 560 / 420px 五档面板宽度下断言
  三件浮层两两零重叠、且都在画布内；fixture 用到的每个类名都先与组件和样式表双向核对，防止 fixture 过期后仍然假绿。
- 反向验证（`pnpm run test:negative`）新增一例：把旧的三件绝对定位注回仓库副本，守卫必须变红
  （实测重叠从 0 变成 2644px²）。
- Agent 侧的 `files[]` 修复有针对性断言：C9 的历史 sink 改成与真实 store 一致的行为，断言回显的 id
  与每张生成图各一条绝对 `.png` 路径——旧写法下这个断言必然失败。

## 已知限制

- 三栏布局（画布约 997px）下，任务工具条只能在左侧 236px 侧列之外的剩余空间里居中，视觉上比窗口正中偏右约 124px。
  这是「不压住缩放按钮」的取舍；要严格居中就得放弃避让。
- 面板窄于约 690px 时任务工具条会折成两行（实测 560px 与 420px 都是 2 行、83px 高）。能点、不重叠，
  但底部被占的高度从 43px 变成 83px。更窄的面板不会继续增加行数，只会有更多按钮留在第二行。
