# v1.22.1 · 深色模式下预览按键回来了，浅色画布也回到原样

> 各版本改动见 [CHANGELOG.md](../../CHANGELOG.md)。

这一版是对 v1.22.0 的修正。上一版修对了症状的**方向**，但两处都选错了 token，
结果一处没修好、一处改坏了不该改的东西。

## 深色模式：全屏预览的按键「都看不到」

不是「太暗」，是**和底色同色**。

v1.22.0 把预览控件的墨色和所有 `color-mix` 基色都取自
`--dsw-alias-label-primary-foreground`。这个名字看起来就是「白色」，但它真正的语义是
**「站在某种实色表面上的反色」**——它跟着主题翻：

| token | 浅色 `body` | 深色 `body[data-ds-dark-theme]` |
| --- | --- | --- |
| `--dsw-alias-label-primary-foreground` | `#fff` | **`#0f1115`** |
| `--dsw-static-neutral-00` | `#fff` | `#fff` |

预览的遮罩本来就是 88% 黑（`--dsw-alias-bg-mask-photo` 叠在最坏情况下是 `#1f1f1f`）。
深色主题下，近黑的底再叠到近黑的遮罩上：

| 元素 | v1.22.0 实测（深色） | 现在实测（两套主题同值） |
| --- | --- | --- |
| 药丸 / 圆形按钮填充 | 1.03:1 | 5.34:1（文字） |
| 描边 | 1.08:1 | 5.41:1（边界） |
| 滚轮提示文字 | 1.11:1 | 5.34:1 |
| 图片说明文字 | 1.15:1 | 5.34:1 |

改成静态色阶 `--dsw-static-neutral-00` 后，**浅色主题一个字节都没变**——它原本解析出来
就已经是 `#fff`，这次只是把「碰巧是白」变成「永远是白」。

### 圆形按钮的填充：40% → 34%

上一轮为了把圆盘抬到 3:1 用了 40% 白填充，可是白图标放在 40% 填充上只有 **4.38:1**，
低于文字要求的 4.5:1——用丢图标换来了边框可见，只是陷阱换了个位置。

34% 是唯一同时满足两边的取值：

```
fill 28%  -> 图标 6.51:1, 圆盘 2.53:1   (圆盘看不见)
fill 34%  -> 图标 5.32:1, 圆盘 3.10:1   (两边都过)
fill 40%  -> 图标 4.38:1, 圆盘 3.77:1   (图标掉到 4.5 以下)
```

边界本来也由 55% 的描边扛着（5.87:1），填充只需自己过 3:1 那条线。

## 无限画布：深色卡片同色修好了，浅色回到原样

**浅色模式原本没有问题，v1.22.0 把它改坏了。**

上一版用 `label-primary` 混 12% 去「一次性修好两套主题」。这个 token 在浅色下近黑，
于是把一个本来没毛病的浅色画布调灰了。

事实是：DSH 的 `--dsw-alias-bg-layer-1/2/3` 在浅色下**全是 `#ffffff`**——白卡片配白背景
就是用户原本要的样子；缺陷只在深色，那里三层是 `#232324 / #2c2c2e / #353638`，相邻只差
大约 1.3:1。

所以现在：

- `.root` 的默认值**退回** `bg-layer-1` / `border-l1`，浅色逐字节不变；
- 深色由 `body[data-ds-dark-theme] .root` 单独覆盖：填充 12% 混色（对画布 **1.44:1**）、
  描边 36% 混色（**3.19:1**）；
- 悬停也拆成变量，浅色仍用原来的 `border-l2`，深色用 46%。

## 测试：两处假绿

两个 bug 原来的检查都是绿的，原因不同：

1. **预览 fixture 把这个 token 硬写成 `#ffffff`，而且只渲染浅色。** 于是「深色主题」这个
   唯一出问题的场景从来没有被画出来过。
2. **画布 fixture 把 `.module.css` 原样塞进 `<style>`。** `:global(...)` 是 CSS Modules
   语法，浏览器见到会**丢弃整条规则**、且不报错——深色覆盖根本没生效，测出来是浅色值。

现在两处都按 DSH 真实的两套调色板各渲染一遍，并在浅色分支上断言「必须仍是 1.00:1」——
只测深色的守卫抓不到「把浅色调暗」这类回归。

新增三条反向用例，把缺陷植回仓库副本后确认检查变红：

| 反向用例 | 期望变红的原因 |
| --- | --- |
| 预览墨色退回跟随主题的 token | `unreadable in a dark theme` |
| 浅色画布被调暗 | `the LIGHT theme's canvas was changed` |
| 圆形按钮丢掉边界 | `not findable in a` |
