# v1.8.0 · 图生图多参考、模板库改成抽屉、等待状态不再骗人

> 各版本改动见 [CHANGELOG.md](../../CHANGELOG.md)。

这一版做了四项：图生图多参考、模板库改成抽屉、等待状态、结果不再裁切。

## 主要更新

- **图生图最多可以用 5 张参考图。**
  第一张走 `image`，其余放进 `images`——只认单张的渠道看到的仍然是一张图，
  所有既有的请求形状不变。上限写在 `reference-images.ts` 一处：
  5 张、单张 10 MiB、合计 16 MiB，面板支持多选、拖拽、粘贴、逐张删除、
  方向键翻页预览，也支持从画廊「加入编辑」。
  **只吃一张的模型会在提交前就被拦下**，并告诉你能用几张，
  而不是把请求发出去、由服务端悄悄截掉；对比模式下取所有目标里最严的那个。

  | 渠道 / 模型 | 上限 |
  |---|---|
  | subscription、chat-completions 族 | 5 |
  | grok-imagine-image、nanobanana 系列、dall-e | 1 |
  | qwen / minimax 且未配 `apiUrlFull`（modelscope 除外） | 1 |
  | 其余 | 5 |

- **模板库从居中的弹窗改成右侧抽屉。**
  默认占工作区约 75% 宽度，宽度记在 `localStorage`（0.55–1），
  可以从左边缘拖动，也可以一键铺满；手机上（≤760px）全宽。
  搜索覆盖全部模板源，最近用过的 24 条留在「历史记录」里一条点击就能再用。
  选中的提示词可以**替换**输入框内容，也可以**追加**在后面。
  有两件事是刻意保留的：`favorites: null` 仍然是「还没读到」，
  所以读取失败显示的是未知状态的星和重试，而不是一整片「未收藏」；
  源标签页仍然走共享的 roving tabindex，方向键能在标签之间移动。

- **等待状态改成点阵，并且每张卡说自己的话。**
  475 个点（对比模式下 130 个）的 SVG 点阵，只靠 CSS 的
  `animation-delay` 走波浪——没有计时器，也没有 React 更新。
  多模型对比时每张卡有自己的点阵，耗时也各自从**这张任务自己的**
  `startedAt` 起算，四个模型不再共用一个误导的秒表。
  失败与取消只停掉自己那张卡，`prefers-reduced-motion` 下不动画。

- **结果图不再被裁掉。**
  结果网格从 `cover` 改成 `contain`，配合零基准的 flex，
  竖图和横图都能完整放进它拿到的那块空间，而不是切掉两边。
  电商套图卡片保留 `cover` 覆盖——那条规则正是商品图不被加黑边的理由。

- **桌面端的更新：宿主能装就在线装，装不了就把命令给出来。**
  `updateInstallTarget()` 现在分 `cli` / `host` / `host-managed` 三态。
  宿主暴露了安装钩子，就用 Release 里那份 tgz 直接装，
  装完核对 `application`、退出码、包名与版本；老宿主不回版本号时回读
  profile 下已装的 `package.json` 再核——**核不到就是失败，绝不当作成功**。
  宿主不提供钩子时仍然抛 `ManualUpdateRequiredError`，面板据此渲染一条
  可复制的安装命令。

- **模板详情的主按钮不再改名字。**
  输入框里已经有内容时，主按钮不会改成「替换」；
  我们两种情况都叫「使用此提示词」，有内容时另外给一个「添加」按钮。
  主操作的含义不会因为旁边有没有字而变化。

- **顺带修掉两处，都是 1.7.8 那次发布暴露出来的。**
  发布任务靠回读 registry 证明「发布成功」，而那次回读比写入晚到了
  **3 分 16 秒**，原来的 60 秒窗口把一次成功的发布报成了失败，还把人指向凭据。
  窗口现在是 5 分钟，窗口耗尽时的报错也分成「我们发布了，npm 退出码 0」
  与「这次运行没发布过」两句；`verify-pack.mjs` 断言这个窗口必须大于 4 分钟，
  反向套件用旧循环证明这条断言会变红。
  另一处是 jsdom 的拆卸顺序：几何观察者是在微任务里被通知的，
  旧代码先删全局再 `close()`，于是稳定打印四行
  `ReferenceError: window is not defined`，而套件仍然报绿。

## 兼容性

- 不新增运行时依赖，无配置变更，无需迁移。
- `localStorage` 新增两个键（最近用过的模板、抽屉宽度），缺失时用默认值，
  不会影响旧数据。
- 面板里的单图状态换成列表，只是内存中的表单状态，没有落盘格式变化；
  历史、画廊、收藏、画布、渠道设置与视频记录都不受影响。
- 单张上限 10 MiB 在客户端与服务端都有；**张数与合计 16 MiB 只由面板把关**，
  服务端只会截断。绕开面板直接调 `/api/dsh-imagegen/*` 时，这两条不生效。

## 安装

```bash
dsh plugin --profile web add https://github.com/q253595422/dsh-imagegen-video/releases/download/v1.8.0/q253595422-dsh-imagegen-video-1.8.0.tgz
```

从本页的 tgz 附件安装：

```bash
dsh plugin --profile web add <下载路径>/q253595422-dsh-imagegen-video-1.8.0.tgz
```

也可以从 npm 装：`@q253595422/dsh-imagegen-video@1.8.0`（由 CI 通过 GitHub
OIDC 发布，带 Sigstore provenance）。

安装后重启 `dsh web`。**DSH Desktop 用户**：桌面版插件目录由应用独占，
请在终端执行上面这条 `dsh plugin ... add`，或在「设置 → 插件」里直接安装这个文件。

## 验证

- `pnpm run typecheck` 通过；`pnpm test` 全链通过——十一道离线检查：
  `verify-tracked`、`verify-reproducible`、`smoke`、`smoke-video`、
  `smoke-canvas-video`、`smoke-video-picker`、`smoke-compose`
  （真实 ffmpeg，零跳过）、`verify-b-defect`、`verify-video-layout`、
  `verify-frame-grab`、`verify-ui-contracts`。
- `pnpm run test:negative` 把每处修复对应的缺陷注回仓库副本，要求对应检查变红。
  本版新增的两条是：jsdom 先删全局再 `close()`（稳定复现那四行
  `ReferenceError`），以及 read-back 窗口退回 60 秒。参考图与抽屉的改动
  由 `verify-ui-contracts` 的既有契约检查覆盖，没有为它们新增变异用例。
- **本版新增一条门禁**：版本号没有对应的 `docs/releases/v<版本>.md` 时，
  `verify-pack.mjs` 直接失败；该文件不在包里也算失败（`files` 里有 `docs/releases`）。
  起因就是这一版的发布说明漏了——`release.yml` 会用那个文件当 Release 正文，
  文件不在时只回落到 GitHub 自动生成的「Full Changelog」一行链接，
  而且只打印一条没人会看的 warning。两条变异用例（改版本号但不写说明、
  从 `files` 里删掉 `docs/releases`）都实测变红。
- npm 发布走 GitHub OIDC、不带任何 token。发布任务在 publish 前会用
  `SHA256SUMS` 校验下载到的 tgz，所以 npm 上那份与 Release 附件是同一批字节；
  1.8.0 也带 Sigstore provenance（npm 页面可见「Built and signed on
  GitHub Actions」）。

### 已知边界（诚实说明）

- **模板抽屉的拖拽只有静态验证。** 宽度记忆、左边缘拖拽、手机全宽都有类型检查
  与契约检查背书，但没有真实指针拖拽的截图或端到端证据；
  `smoke.mjs` 里的模板断言跑在 jsdom 上，不带真实指针事件。
- **图生图的张数上限只在面板里。** 见上文兼容性一节：服务端只截断。
- 本版没有改动其他链路的行为；画布、视频与拼接的上一轮成果在 1.7.5–1.7.7。
