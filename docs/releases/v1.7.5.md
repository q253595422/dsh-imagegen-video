# v1.7.5 · 全部 UI 模块过一遍：主题、标注色、层序都收敛到一处

> 本仓库自己的发布说明。相对上游 v1.6.8 的完整改动见 [CHANGELOG.md](../../CHANGELOG.md)。

这一版不是加功能，而是把界面里**会互相打架的东西**收敛到单一来源。
判据是「去掉修复后，对应检查必须变红」，而不是「看起来改好了」。

## 主要更新

- **导航栏跟随宿主主题变化。**
  `GooeyNav` 的四个颜色原先写死成字面量，而且只在挂载时探测一次表面颜色；
  宿主在它显示期间切浅色/深色，它仍按旧表面作画，在新底色上读不清。
  现在配色从 `--dsw-alias-*` 变量派生，并新增 `surface-theme.ts` 订阅，
  在宿主属性（含 DSH 的 `data-ds-dark-theme`）、系统偏好、以及被重新挂载时
  都会重新推导。**注意 `--dsw-alias-brand-primary` 是中性反转色、不是强调色**
  （浅色下近白、深色下近黑）——它按中性色使用，标注红刻意不用它。

- **标注色成为一个变量，CSS 与画布两侧同源。**
  画布上看到的标注框由 CSS 上色，而烧进图片里的画框由 Canvas2D 用 `#ff2d55`
  字面量画——两边会漂移。现在都读 `--canvas-annotation`。
  因为该变量声明在画布根类上、不在 `documentElement` 上，
  `themeColor()` 增加了 `origin` 参数，调用方传入画布根节点；
  从文档根读会永远拿到空串并静默回退到字面量，等于没修。

- **统一的 z-index 表，且不重编已经正确的层序。**
  模块样式表里的字面量全部改为 `panel.module.css` 里的一张有文档的表。
  **数值就是各层原本的值**，只有真正**同号**的才拆开，且只拆到刚好保住
  原有比较关系为止（1000 → 1000/1005/1010，130 → 130/131/132，
  60 → 60/61/62，70 → 70/72，20 → 20/21）。这些同号是真实的：
  谁压谁由文档顺序决定，一次无害的重构就能改变堆叠。
  守卫有三重——文档表必须与声明逐条一致、26 条必需的先后关系必须成立、
  以及三个与宿主外壳交界的档位按值钉死；另有一条**真浏览器**检查，
  把其中一对原同号层按**相反**顺序渲染，要求胜者不变。

- **浮层不再顺带清空画布选择。**
  所有浮层（输入条、菜单、弹窗）都是视口的兄弟节点，
  所以在浮层上按下指针不会传到视口处理器。这条现在用**结构断言**保证，
  而不是靠一段实际为死代码的守卫。

- **触屏支持双指缩放。**
  两个触摸点分开即缩放画布，与触控板行为一致。

- **键盘可达性。**
  坞站按钮获得焦点后按空格是激活按钮，不再被平移处理器吞掉；
  Esc 能关闭画布内视频预览、技能菜单、润色弹窗与视频拾取器；
  节点隐藏的悬浮工具条退出 Tab 顺序、并由焦点唤出，
  Tab 不再落在看不见的控件上（包含删除按钮）；
  所有 `role="tablist"` 都接上共享的 roving-tabIndex + 方向键契约。

- **读取失败不再伪装成空列表。**
  历史、素材库、模板收藏在读取失败时显示「这里还没有内容」。
  现在会显示失败原因与重试；收藏状态读不到时显示「未知」标记，
  而不是一颗看似「未收藏」的星。

## 兼容性

- 不新增运行时依赖，无配置变更，无需迁移。
- 画布数据、历史记录、素材库、模板与渠道设置全部不变。
- z-index 表的数值改动只影响**原先同号**的那几层；其余层序逐位保持原样
  （与上一版对比，全仓仅 8 处层号发生变化，且都有记录）。

## 验证

- `pnpm run typecheck` 通过；`pnpm test` 全链通过（含 `smoke`、
  `smoke-video`、`smoke-canvas-video`、`smoke-video-picker`、`smoke-compose`、
  `verify-b-defect`、`verify-video-layout`、`verify-frame-grab`、
  `verify-ui-contracts`）。
- 涉及布局的三项都在**真实浏览器**里实测，不是读源码推断：
  层序（在**反转 DOM 顺序**下实测遮挡关系）、悬浮工具条的可见性与焦点、
  输入条占满面板宽度（实测 976/1010px）。
- 每处修复都做了反向验证：`pnpm run test:negative` 共 **24 个变异**
  （contracts 19 + smoke 5）**全部**让对应检查变红，包括
  「把下拉层降回 60 让它掉到自己的弹窗之下」「恢复 60/60 同号」
  「把文档表改得与声明不一致」等。反向验证在仓库副本上进行，工作树不被改动。

### 已知边界（诚实说明）

- `settings-card` 的 `.presetInline` 与 `.footer` 在**上一版**就存在层序翻转
  （10 压在 4 之上，改表后变成 2 在 3 之下）。本版按「保住既有行为」处理，
  未改变其可见结果；是否要重新设计这两层的意图，留待后续决定。
