## 服饰穿戴：两种模式

- **商品试穿**：拿真实商品图当服装参考，保留版型、颜色、图案与材质。人物与至少
  一张服装图是必选。
- **角色搭配**：把参考服装设计穿到人物身上。人物、服装、姿势三类素材任选其一以上，
  也可以和自己的图混着用。

## 素材从哪里来

人物、服装、姿势各有一套内置图库。选图器支持按名称或标签搜索，按分类与来源筛选，
姿势还能按视角筛选；服装条目带多视角可切换，姿势可选深度图。18+ 素材默认不显示，
需要时手动打开。

图库可以**完全离线使用**：把 `anhao/ai-pose-gallery-zh` 克隆到本地后填目录路径即可
导入整份图库；其余情况索引与图片按需缓存到 `~/.dsh/dsh-imagegen/outfit/`，选中后读的
是本地副本，第三方站点失效也不会中途失败。

索引与图片都按 Git blob 校验，站点不可达时换镜像重试，并用图片魔数确认拿到的确实
是图片；更新失败时继续使用已有离线索引，并在面板上说明原因。

## 提交前先看预览

点「准备参考图预览」**只下载与排版参考图、不调用模型**，右侧给出实际会发送的图片与
完整提示词；确认后才调模型。

任何编辑、换渠道或换模型都会让预览失效，需要重新准备——避免「看到的」和「发出去的」
不是同一份。

**参考素材超过渠道容量时压成一张编号拼图。** 一部分模型只收一张参考图，以前多出来的
会被静默丢掉；现在把全部素材排进一张带「图 N 用途」标注的拼图，提示词同步改成按格子
编号指代，预览里也说明这次发的是一张拼图。拼图按原比例留白，不裁切服装或姿势。

## 草稿自动保存

模式、素材、场景、比例、清晰度与所选模型都留在本机，编辑停顿约 0.35 秒即写入，
下次打开接着改。

## GIF 动图

- **支持 `gpt-image-2.6` 生成 GIF。** 面板新增「静图 / GIF 动图」切换，选了 GIF 才
  出现帧数与每帧时长；请求按 `output_format: 'gif'` 整形，帧数夹在 2–16、每帧不短于
  20ms，超出的按上限收窄而不是发出去被上游拒绝。
- **不支持的模型与渠道在发请求前就拒绝。** GIF 请求先过能力闸再分派协议：模型不支持、
  或渠道协议是 `chat-completions`（该请求体根本没有 `output_format` 字段，模型再新也
  只会出静图）时立即报错，不会静默降级成一张静图却照常计费。订阅渠道同样明确拒绝。
- **帧数与时长只有一个真值。** 面板上的时长提示、提交的参数、引擎的夹紧用的是同一个
  函数：清空输入框按「未设置」回落默认值，而不是一处按默认、一处按下限。
- **GIF 期间不能切到不支持的形态。** 「图生图」与「对比」置灰并说明原因；生成数量
  固定为 1 并注明理由，因为 GIF 受上游像素预算限制只能出单张。
- **动图在结果板、历史、画廊与画布里都按动图处理。** mime 按字节魔数判定
  （GIF87a/GIF89a），下载扩展名、历史标记与画廊落盘都认 gif，预览用浏览器原生播放，
  不会只显示第一帧。

## 已知边界

- **参考图片的权利归各来源原作者所有**，不适用本插件的代码许可证；使用时请遵守原站
  条款，部分素材不允许商用。面板底部显示当前素材的来源说明与原始链接。
- 这一版不改变「草稿读失败」本身的发生概率。**它留下的那个交互缺陷在 v1.23.1 才修**：
  草稿读取失败时整张表单被永久禁用，用户看到的是「角色搭配点了没反应」。
