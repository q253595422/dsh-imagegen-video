# v1.19.0 · Seedream 水印开关与技能目录隔离

本版合并上游 v1.10.0 的 Seedream 水印控制能力，并为本地技能存储增加安全隔离机制。

## 主要更新

- **Seedream 水印开关**：
  - 渠道配置新增「图片添加「AI 生成」水印」开关（默认开启）。
  - 关闭开关后，文生图与图生图请求体透传 `watermark: false`，上游不再向原图右下角压印「AI 生成」角标。
  - 严格限制仅对火山方舟 / BytePlus 官方域名（`volces.com` / `byteplus.com` / `bytepluses.com`）及官方模型 id 透传该参数，避免第三方 OpenAI 兼容中转网关因未声明字段返回 400。
  - 支持中、英、俄三语设置文案与合规提示。
- **技能目录隔离（`DSH_SKILLS_HOME`）**：
  - 允许通过 `DSH_SKILLS_HOME` 环境变量覆盖默认技能存储路径，防止自动化探针及测试套件安装/卸载技能时影响用户宿主真实的 `~/.dsh/skills`。

## 安装

从 DSH 插件市场安装：

```bash
dsh plugin --profile web add @q253595422/dsh-imagegen-video@1.19.0
```

本地安装发布产物：

```bash
dsh plugin --profile web add ./q253595422-dsh-imagegen-video-1.19.0.tgz
```
