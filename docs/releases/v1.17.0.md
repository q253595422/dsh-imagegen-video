# v1.17.0 — 电商六件套：多参考图、爆款复刻、服饰穿戴、上架文案、A+ 详情页、带货图文

一句话概括：把 designkit 那套「AI 商品套图」的能力补齐到本插件里。这一版新增五个工作区，底座先做对——参考图带着角色真传给模型，而不是过去那样只在提示词里拼一句「参考第 2 张」。

## 为什么

过去的电商模式只有一条链：一个 slot 出一组图，参考图按 `slot.refRole` 过滤之后，**只把第一张**放进 `image`，其余全部丢掉，提示词里补一句「共 N 张：第 1 张为商品主体」。宿主引擎其实早就支持多张（`src/protocol.ts` 的 `images?: string[]`，`src/engine.ts:955-958` 会 append），缺的一直是前端真的把图传出去。

所以这一版先修底座，再往上长功能：底座做错，上面五个模式都要返工。

## 做了什么

### 底座：参考图按角色真传

- `EcommerceRefRole` 扩展为 `none | product | packaging | detail | style | layout`（`src/protocol.ts`），新增 `layout`（版式参考）。
- 提交时按角色筛出的图**全部**发送：`[primary, ...extras]` 分别进 `image` 与 `images`（`src/client/ImageGenPanel.tsx` 的 `handleEcommerceGenerate` / `buildRequest`）。
- 上限是引擎的真实上限，不是界面上的好看数字：`EDIT_REFERENCE_LIMIT = 5`；grok 与 nanobanana 只吃单张，多传的会被上游丢弃，界面写明。

### 五个新模式

| 工作区 | 说明 |
|---|---|
| 爆款图复刻 | 传一张爆款图，按复刻程度与复刻要求重排。`ReplicaWorkspace.tsx` + `replica-prompt.ts`（390 行）+ `replica-capacity.ts` |
| 服饰穿戴 | 服装图 + 模特图 + 场景预设，模特形象落盘 `~/.dsh/dsh-imagegen/models/`，可用 AI 生成模特 |
| 商品上架文案 | 标题 / 五点描述 / 关键词，多语言，走既有提示词增强通道 `PROMPT_ENHANCE_API.enhance` |
| A+ 详情页 | 12 个模块（品牌海报、核心卖点、场景共鸣、细节特写、参数对比、使用步骤、模特上身、信任背书、套装清单、规格表、常见问题、结尾海报），可排图上文案，导出整张长图 |
| 带货图文 | 3:4 竖版图 + 可直接粘贴的文案（标题 / 正文 / 话题标签），支持粘贴商品链接自动抓取 |

导航从 6 项变 9 项：普通生图 / 素材库 / 无限画布 / 电商模式预览 / 图片转 PPT / 爆款复刻 / 服饰穿戴 / 带货图文 / A+ 详情页。

### 商品套图补全

- **白底图平台合规**：勾选后只作用于主图——提示词写入「背景必须是纯白 #FFFFFF，严禁文字、水印、Logo 叠加、边框、投影、道具、场景，商品占画面至少 85%」，尺寸强制 `1:1`，界面同步写明比例被锁。
- **版式参考（layout）**：卖点图可以传一张版式图学排版，图真传，不只是拼文字。

### A+ 长图：零新依赖

`aplus-layout.ts` 算块位（宽 750 / 970 / 1200，间距 0 / 16 / 32），`aplus-draw.ts` 用浏览器 `<canvas>` 绘制并 `toBlob` 导出 PNG，`aplus-text.ts` 负责折行与文案带。没有引入 `sharp`、`node-canvas`、`puppeteer`，也没有用 `foreignObject`（跨域会污染画布）。

护栏：总高超过 `APLUS_MAX_HEIGHT = 16000` 直接拒绝并提示；文案带高超过块高 40% 时先缩到 0.6 倍再拒绝——**拒绝，不截断**，那一块保留图片，界面报出是哪一块。

### 商品链接抓取（降级实现）

宿主侧抓页面，JSON-LD 的 `Product`（含 `@graph` 里嵌套的）优先，og 标签兜底，抽标题 / 主图 / 卖点 / 价格。抓不到就回退手填，不假装成功。

SSRF 硬拦：只允许 `http` / `https`；私有段、回环、`169.254.169.254`、`metadata.google.internal` 这类云元数据域名、`.internal` / `.local` / `.home.arpa`、**任何 IP 字面量**、**单标签主机名**全部拒绝；`redirect: 'manual'` 最多 4 跳且每跳重新校验；8 秒超时；2 MiB 上限；`content-type` 必须是 HTML。

## 顺带修的既有缺陷

- **导航压住「展开右侧对话」**：820–1000px 宽度下导航栏把对话按钮盖住，点不到。这不是新功能引入的，1.16.1 就已经存在（5 个 tab 时就会发生）。修法是把 `overflow-x: auto` 与 `nav { width: max-content }` 从 `@media (max-width: 760px)` 提为无条件——宽度不够时导航自己横向滚动，不再压别人。
- **服饰穿戴上传 6 张只发 4 张**：多出来的 2 张被静默丢弃。现在上传上限就是 4 张，文案写明「连同模特图共 5 张，正好是引擎的参考图上限」。
- **模特库路径逃逸**：`index.json` 里的 `file` 字段带 `..` 时能读到 models 目录外。现在 `safeFileName()` 是唯一入口，`routes.ts` 的资源路由再做一次段级防穿越，模板路由两段路径单独校验。
- **`smoke-canvas-video.mjs` 的 E1 是 flake**：判据依赖轮询时序，曾把 1.16.1 的发版卡红一次。改为等待确定状态，不加任何重试。
- **A+ 文案带是不透明白盒子**：第一版先铺不透明纸白再叠半透明白，图上一点透不出来。现在只留一层 `rgba(255,255,255,0.92)`，蓝图上的带子是 `235,235,255`。

## 已知缺口

- **A+ 预览里不叠字**：文案只出现在导出的长图上，工作区缩略图里看不到。留到 1.18。
- **Windows 上折行未验证**：字体栈用系统字，PingFang 与微软雅黑的度量不同，Windows 导出的折行位置可能与 macOS 略有差异。
