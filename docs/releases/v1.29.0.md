# v1.29.0 — 插件改名「团团TV」

本版只做一件事：**把插件在界面上显示的名字定为「团团TV」**。包名 `@q253595422/dsh-imagegen-video` 不变（npm 的包名不允许中文，也不该为了改显示名去动它），改的是用户看到的那一层。

## 为什么要改

插件详情页此前显示的标题是**完整的包名**：`@q253595422/dsh-imagegen-video`。

原因不在包名写错了，而在插件详情页的标题来源：宿主从插件包的 `locale/<语言>.json` 里读 `meta.title`，**没有声明这个字段时回退到 manifest 的 `name`**，也就是完整包名。本仓库的 `locale/zh.json` 与 `locale/en.json` 当时只声明了 `meta.description`，于是标题就一路回退成了包名——面板里、侧边栏里、设置里的名字也都各写各的（`AI 生图`、`VisioWork`、`Image settings`），三者并不一致。

## 改了什么

- **声明插件显示名**：`locale/zh.json` 的 `meta.title` 为「团团TV」，`locale/en.json` 为「TuanTuan TV」。宿主按当前界面语言取对应值，两者都不再回退到包名。
- **界面内三语品牌文案统一**：`entry.label`（侧边栏入口）、`panel.title`（工作台面板标题，原为 `VisioWork`）、`settings.title`（设置卡标题）、`config.disabledTitle`（插件停用提示）在 zh / en / ru 三种语言里都换成同一个名字。
- **Agent 指导文案**：`IMAGEGEN_GUIDANCE` 里「本机已安装 dsh-imagegen 插件（DSH AI 生图）」改为「本机已安装团团TV（TuanTuan TV，包名 dsh-imagegen）」，保留包名是为了让模型仍能对上实际安装的模块。
- **`/edit_image` 成功提示**：由「可在 AI 生图面板查看结果」改为「可在团团TV 面板查看结果」。
- **README 标题**改为「团团TV（TuanTuan TV）」，正文标注实际包名。

**没有改的**：设置里的分区名「生图配置 / Image settings / Настройки генерации」。它是**位置名而不是品牌名**——后端有 22 处错误提示写着「请打开设置 → 生图配置」，改它就得分批同步那些提示与三条测试断言，而它本身并不承担品牌职责。

## 测试

新增 `smoke` 的 **D6**：断言 `locale/zh.json` 与 `locale/en.json` 都声明了非空的 `meta.title`、中文标题确实是「团团TV」、英文标题不是包名、并且与界面里的 `panel.title` / `entry.label` 一致。**反向验证过**：删掉 `meta.title` 后 D6 变红（`zh.json declares meta.title`），还原后转绿。这条守卫存在的意义是 `meta.title` 是纯展示字段，没有任何运行时代码读它，漏写不会有别的检查报错——只会在用户眼前悄悄变回一串包名。

`pnpm run typecheck`、`pnpm build`、`node scripts/smoke.mjs`、`node scripts/verify-tracked.mjs`、`node scripts/verify-pack.mjs` 全部通过；打出的 tgz 内 `package/locale/zh.json` 与 `package/locale/en.json` 已确认带上新的 `meta.title`。

**未验证**：真实宿主插件详情页的渲染结果——那需要重启 DSH 桌面应用后由用户目视确认。
