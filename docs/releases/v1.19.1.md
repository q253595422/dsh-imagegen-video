# v1.19.1 · 修正提示词换行展示位置

本版修正历史提示词换行与截断展示位置，恢复侧栏卡片整洁，并在右侧大图详情区域完整展示提示词。

## 主要更新

- **左侧边栏历史卡片恢复 2 行截断**：
  - 修正此前全局去掉行数截断导致左侧长文本卡片被撑得过长、破坏列表平衡的问题。
  - 左侧 `.historyPrompt` 恢复 `-webkit-line-clamp: 2` 截断与文本省略（ellipsis）。
- **右侧结果区顶部大图上方提示词独立完整展示**：
  - 在大图上方的元数据区域增加 `.canvasPromptLine` 独立行，完整保留换行（`white-space: pre-wrap`）。
  - 支持文本自由划选与复制（`user-select: text`），下方或后方紧跟生成参数标签。
  - 图片生成与视频生成结果视图同步生效。

## 安装

从 DSH 插件市场安装：

```bash
dsh plugin --profile web add @q253595422/dsh-imagegen-video@1.19.1
```

本地安装发布产物：

```bash
dsh plugin --profile web add ./q253595422-dsh-imagegen-video-1.19.1.tgz
```
