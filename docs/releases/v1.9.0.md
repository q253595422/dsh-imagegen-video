# v1.9.0 · 图片转可编辑 PPT

> 各版本改动见 [CHANGELOG.md](../../CHANGELOG.md)。

新增独立的「图片转 PPT」工作区：上传图片，每张图片对应一页幻灯片，转换结果为可编辑的 PPTX。
生图、图生图和对比结果里都多了一个「生成可编辑 PPT」入口，点一下就把图带进这个工作区。

## 主要更新

- **图片转 PPT 是独立工作区。** 上传 PNG / JPG / WebP，最多 12 张、单张 20MB；
  缩略图可以排序和删除，顺序就是幻灯片顺序。转换有真实状态：进行中、可取消、
  完成可下载，输入图片保留下来可以再转一次。

- **结果页与对比页都能一键带入。** 文生图、图生图结果、多模型对比结果以及放大预览
  都加了「生成可编辑 PPT」，点击后带着这张图切到 PPT 工作区。

- **配置区新增 PPT 专区。** 在「设置 → 生图配置」里：安装或更新官方技能、
  安装并检查隔离的 `editppt` Python 环境、配置图像 API 与 PaddleOCR token。
  密钥沿用设置里的脱敏存储，不进入任务提示词。

- **OCR 两种方式可选。** PaddleOCR，或本次转换自带的离线文字检测。

- **失败是失败，不是空白。** 没有产出 PPTX、ZIP 无效、页数对不上，都按失败报告；
  宿主重启后未完成的任务显示为中断，可以重新发起。

## 前提

Python 3.10+；DSH 已配置默认模型，并启用技能与长任务；Agent 预设需要提供文件与命令工具。
多页转换按技能自己的方式跑页任务，需要预设支持子 Agent。PaddleOCR token 可选；
图像后端需要有效的 Codex OAuth 或兼容图像 API。

## 其他

- 画布顶部导航在窄屏（≤760px）下可横向滚动，标签不再被挤出屏幕外。
- 设置区在窄屏下允许换行，不再把摘要挤成一条。

## 验证

类型检查、构建与全部 187 项离线检查通过。新增的 `C6c4` 覆盖 PPT 三个路由的请求校验
（图片数量、asset id 的路径语法、OCR 方式必填）与拒绝时的原因说明；
撤回路由里的 asset id 校验后该检查确实变红。

尚未在真实付费模型上完整跑通一份多页转换——转换质量取决于输入图片、OCR 与模型能力。
