# v1.27.0 — 千问生图 API；大图预览可按住拖动

本版是 **v1.24.0 之后的第一个发布版本**，把已合入 main 但一直没发出去的三批改动一起放出：1.25.0 的 react-flow 画布引擎、1.26.0 的画布布局对齐 LibTV，以及本次的千问生图协议与预览拖拽修复。1.25.0 / 1.26.0 没有各自的 tag 与 Release，它们的完整改动见 [v1.25.0](./v1.25.0.md) 与 [v1.26.0](./v1.26.0.md)，都包含在本版的安装包里。

## 本次新增

### 千问生图 API 协议（#32）

渠道「接口协议」新增 **千问生图 API**，支持文生图与图生图：

- 走 DashScope 的异步任务链路：提交任务拿 `task_id`，再轮询任务接口取结果，轮询上限 240 秒，超时抛 `upstream-timeout` 而不是一直挂着。
- 任务状态分三类识别：进行中（`queued` / `pending` / `running` / `processing` / `in_progress`）、完成（`done` / `completed` / `succeeded` / `success`）、失败（`failed` / `failure` / `error` / `cancelled` / `canceled`）；出现词表之外的状态直接报 `upstream-invalid`，不当成「还在跑」无限等下去。
- 比例按 API 文档档位发送；面板的 **21:9 没有对应档位，按最接近的 16:9 发送**。清晰度映射到 `megapixels`，**上游上限 2MP，所以 2k 与 4k 都取最高档**。
- 图生图上传参考图的原始字节，不做二次转码。
- API Key 为空时不发送空的 `Bearer ` 头。
- 渠道支持模型检测；协议选项与提示文案补齐 zh/en/ru。

### 修复：配置里的 Google 原生协议被 schema 拒绝

`src/index.ts` 的 schemastery `protocol` 联合只列了 `auto` / `images` / `chat-completions`，漏掉了类型里早已存在的 `google-native`。用真实 schemastery 实测：旧 schema 对 `protocol=google-native` 报 `expected "auto" | "images" | "chat-completions" but got "google-native"`，新 schema 通过。这是 #32 顺带修掉的一个独立缺陷，与千问协议无关。

### 修复：大图预览放大后无法拖动（#31）

生成成功的图片点开大图、放大之后，以前只能拉旁边的滚动条才能看到画面其余部分。现在**按住鼠标左键直接拖动画面**即可平移：

- 用 pointer 事件接管，`setPointerCapture` 保证指针移出图片也不丢拖动；反向写 `scrollLeft` / `scrollTop`，移动距离与鼠标一致。
- 光标在可平移时是 `grab`，拖动中变 `grabbing`，松手复原。
- **拖动之后紧跟的那一次 click 不会误关预览**：抑制器挂在浮层的捕获阶段且只吞一次，随后的普通点击照常关闭。
- 只接管鼠标主键；触摸交给浏览器原生滚动，内容没有溢出时不拦按下。图片本身禁用原生拖拽，避免拖出幽灵图。

## 一并发布的前两批

- **1.25.0 — 无限画布换用 react-flow 引擎**：`@xyflow/react` v12 做受控视图，`CanvasDocument` v2 仍是唯一真源，磁盘数据零破坏；节点拖动/吸附、四角 resize、连线、捏合缩放、框选与快捷键全部保留；新增无损适配层与 LibTV 式缩放菜单、视图开关。
- **1.26.0 — 画布布局对齐 LibTV**：悬浮顶栏、左下工具排、六组分隔 dock、空态五张快捷卡；并修掉真机走查发现的两个手势缺陷（框选抢走快捷卡 click、react-flow wrapper 的 `pointer-events:none` 继承导致卡片拖不动）。
