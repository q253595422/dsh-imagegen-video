# v1.7.1 · 补上 1.7.0 漏发的两条修复，并补齐发布卫生

> 本仓库自己的发布说明。相对上游 v1.6.8 的完整改动见 [CHANGELOG.md](../../CHANGELOG.md)。

1.7.0 的 Release 资产上传时，有两条修复还没落地；而版本号没有跟着升，导致应用内
更新按钮**永远不会亮**（`updateAvailable` 用严格大于比较），用户也就永远收不到它们。
本版把这两条带上，并补掉「发布可以零自动校验地出去」这一类缺口。

## 主要更新

### 补上 1.7.0 之后滞留在 main 的两条修复

- **瞬时状态抖动不再判死视频渲染**：轮询对 5xx / 429 / 传输错误在有界预算内重试，
  而不是把一条要渲染几分钟的任务直接标成失败；预算用尽时报上游自己的错误信息。
- **不可满足的 `Range` 返回 416**，不再静默回 200 加整个片段。

### 资源有界（宿主侧）

- 生图与视频任务队列只保留最新的终态任务（200 / 100 条）以及全部进行中的任务。
  一条完成的生图任务会钉住它的 base64 结果，此前无界数组会把整个会话生成过的图片都留在内存里。
- 重任务技能跑完后会删除它的运行目录。此时产物已被读进画布资产库，这正是删除安全的依据。
- 删除画布会回收不再被引用的资产。回收**刻意保守**：任何一个页面文件解析失败就整轮放弃，
  所以这里出 bug 只会留下垃圾，不会删掉正在用的文件。两个引用源都会收集：`metadata.asset` 与 `backgroundImage`。

### 数据根统一

- 「打开数据目录」路由、模板快照缓存与模板收藏此前硬编码 `~/.dsh/dsh-imagegen`，
  而历史 / 素材库 / 视频 / 画布走的是尊重 `DSH_HOME` 与 `localStoragePath` 的 `imageDataRoot()`。
  设了这两者之一，按钮会打开错误目录，模板数据也另居一棵树。四处现已统一走 `imageDataRoot()`，
  并且是**惰性求值**，所以导入之后才设置的路径同样生效。

### 网络调用有了上限

- 提示词增强与 `/models` 探测有界（60s / 30s），图层拆分的视觉调用有界（120s）。
  超时与调用方自己的取消信号是**组合**关系，不是替换。

### 画布界面

- 片段已失效的视频节点（历史被清空，或被 30 条上限淘汰）现在会明确说明，并给出重试与移除入口，
  而不是渲染一个没有任何解释的坏播放器。
- 画布并发保存冲突的自愈改为判定稳定的 `canvas-conflict` 错误码，不再匹配会被翻译的文案。
- 工具视图、面板拖拽柄、视频面板与画布里的硬编码中文移入 locale 字典，
  英文与俄文界面下不再显示中文。

### 发布与验证

- `package.json` 的 `files` 不再发布 `docs/videos/`（37 MiB 演示录像，没有任何随包文档引用它）与其余 `src/`；
  内置提示词快照保留，因为运行时会相对 `lib/` 读它们。
- **新增 CI**（`.github/workflows/ci.yml`）：类型检查、构建、装了 ffmpeg 之后跑完整套件，
  以及检查打包产物——缺运行时文件、或演示录像又回来了，都会让 CI 失败。
- `scripts/verify-frame-grab.mjs` 进入 `pnpm test`，并且每次运行使用全新的浏览器 profile
  ——固定路径会让它第二次运行就失败，且只报「CDP did not come up」而不给原因。
- `scripts/verify-video-layout.mjs` 会拿 fixture 的类名去核对真实组件与样式表，
  类名被改名时守卫会失败，而不是继续量一段组件已经不再渲染的标记。
- `scripts/smoke.mjs` 有了每检查超时；它的数据目录断言改为检查路由遵循 `DSH_HOME`，
  不再断言字面量 `.dsh`——旧断言之所以通过，恰恰因为路由是硬编码的。
- `scripts/smoke-compose.mjs` 会报告跳过了多少项检查，缺 ffmpeg 时不再看起来像一次干净的运行。
- 更新安装器拒绝 GitHub 自动生成的源码归档（`<仓库名>-<tag>.tar.gz`）：
  它不含构建产物，装出来是个无法加载的插件。

## 兼容性

- 不新增运行时依赖；渠道、历史、素材库、模板与画布数据无需迁移。
- 数据根统一后，若你此前设过 `DSH_HOME` 或自定义 `localStoragePath`，模板快照缓存与收藏会
  跟随该路径；旧目录下的同类数据不会自动搬过来，需要手工移动。

## 安装

```bash
dsh plugin --profile web add https://github.com/q253595422/dsh-imagegen-video/releases/download/v1.7.1/q253595422-dsh-imagegen-video-1.7.1.tgz
```

从本页的 tgz 附件安装：

```bash
dsh plugin --profile web add <下载路径>/q253595422-dsh-imagegen-video-1.7.1.tgz
```

## 验证

- `pnpm exec tsc --noEmit` 通过；`pnpm test` 全链通过（七个套件，含真实 ffmpeg 的拼接用例与两个真实浏览器守卫）。
- 发布产物实测 23 MiB（1.7.0 约 59 MiB），`package/lib/index.js`、`package/src/templates/cases.json`、
  `package/cordis.patch.yml` 均在包内，`package/docs/videos/` 已排除。
- 队列终态上限、画布资产回收（含 `backgroundImage` 引用源与解析失败时的保守行为）都有临时脚本实测过。
