01
安装与进入

装好之后
侧栏多一个「生图」

一条命令装上，重启 dsh web，侧边栏就多出「会话 / 生图」两个页签。

需要 DeepSeek Harness + Node.js 20 以上
别和 @dickpy/dsh-imagegen 同时装，路由会撞
会话 / 生图
02
配置渠道

先告诉它
去哪儿生成

设置 → 生图配置：填 API 地址与密钥，点「检测模型」勾选，保存。

图片模型与视频模型分开配
没配好时面板会直接提示「尚未配置 API」
03
第一张图

写一句话
点「开始生成」

尺寸、清晰度、张数按需调；不满意就改提示词重来，历史都在。

尺寸：1:1 / 16:9 / 9:16 等九档
清晰度 1K–4K · 一次最多 4 张
真机生成
04
图生图

五张参考图
一起喂

风格、人物、构图分开给；拖拽、粘贴、批量选择都行。

最多 5 张 · 单张 ≤10MB · 合计 ≤16MB
超出张数在提交前就拦下，不靠服务端截断
05
生视频

图片定好
一句话让它动

文生视频 / 图生视频 / 首尾帧 / 参考图，异步渲染，关掉页面也在跑。

先规划：先把一句话拆成镜头与运镜再发
5s / 10s · 480P–1080P
真实成片 · 5s
06
无限画布

整条流程
摊在画布上

图片、视频、文本、配置节点连线；改哪步只重跑哪步。

图片与视频节点同一套控制
按 ? 呼出快捷键表
07
分镜 · 拼接 · 时间线

多段合成
一条成片

分镜一镜一段；框选几段按画布位置拼；要剪再接就开时间线。

顺序按画布位置：从上到下、从左到右
本机 ffmpeg，不联网、不消耗额度
① ② ③ 按画布顺序
08
电商套图与模板库

成套出图
不用从零写

商品参考图生成主图、卖点图、场景图；模板库里挑现成提示词。

八个来源的模板库，可搜索、可收藏
删除进回收站，30 天内可恢复
装上就能用
$ dsh plugin --profile web add @q253595422/dsh-imagegen-video
