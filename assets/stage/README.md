# Stage base body assets

`base-body.glb`, `clothing-tshirt.glb`, `clothing-jeans.glb` and
`clothing-shoes.glb` are the CC0 MakeHuman system assets exported by the
[kblood/CharacterCreator](https://github.com/kblood/CharacterCreator) build
(`output/`). The MakeHuman source assets are CC0; only these generated GLB
assets are used here, not the CharacterCreator GPL source code.

- Source: https://github.com/kblood/CharacterCreator
- Base body licence: MakeHuman CC0
- Clothing source: MakeHuman CC0 system asset pack
- Export date: 2026-10-01

The stage overrides their skin/clothing materials with the plugin's figure
palette and applies the male macro morph before driving the 53-bone rig.
